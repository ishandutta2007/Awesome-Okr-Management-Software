## 🏢 SaaS / Commercial Platforms

The note-taking market has consolidated around a few dominant platforms offering freemium models with AI features as the primary upsell. Evernote recently restructured its plans, retiring Personal/Professional tiers in favor of Starter ($6.65/mo annual) and Advanced ($16.65/mo annual) [citation:2][citation:11]. Obsidian remains free for all uses including commercial, monetizing only sync ($4/mo) and publish ($8/mo) [citation:13]. Notion’s free tier supports personal use with up to 10 guests, while business plans start around $18/user/month with typical negotiated discounts of 15-25% for larger teams [citation:3][citation:12].

## 🔓 Open-Source GitHub Projects

*Sorted by GitHub_Stars_Count (Descending)* 🌟

- **[Joplin](https://github.com/laurent22/joplin)** [![Stars](https://img.shields.io/github/stars/laurent22/joplin?style=social&color=white)](https://github.com/laurent22/joplin/stargazers)  
  **Open-source Evernote alternative with E2EE**, AGPL-3.0 licensed. Cross-platform (Windows, Linux, macOS, iOS, Android, CLI), syncs via Joplin Cloud, Dropbox, OneDrive, Nextcloud, or WebDAV. Imports from Evernote. Notes stored in SQLite database [citation:9][citation:18]. 📓

- **[Logseq](https://github.com/logseq/logseq)** [![Stars](https://img.shields.io/github/stars/logseq/logseq?style=social&color=white)](https://github.com/logseq/logseq/stargazers)  
  **Local-first, block-based outliner for knowledge management**, AGPL-3.0 licensed. Bi-directional linking, daily notes, Zettelkasten-style workflows. Stores notes as plain Markdown files on disk. Available on F-Droid for Android [citation:18]. 🧠

- **[SiYuan](https://github.com/siyuan-note/siyuan)** [![Stars](https://img.shields.io/github/stars/siyuan-note/siyuan?style=social&color=white)](https://github.com/siyuan-note/siyuan/stargazers)  
  **Privacy-first, self-hosted personal knowledge management**, AGPL-3.0 licensed. Block-level references, Markdown WYSIWYG, PDF annotation, and end-to-end encrypted sync. Electron/TypeScript + Go [citation:9]. 🔒

- **[AppFlowy](https://github.com/AppFlowy-IO/AppFlowy)** [![Stars](https://img.shields.io/github/stars/AppFlowy-IO/AppFlowy?style=social&color=white)](https://github.com/AppFlowy-IO/AppFlowy/stargazers)  
  **Open-source Notion alternative**, AGPL-3.0 licensed. Kanban boards, databases, wikis, and collaborative editing. Built with Flutter and Rust for cross-platform performance. 🧱

- **[AFFiNE](https://github.com/toeverything/AFFiNE)** [![Stars](https://img.shields.io/github/stars/toeverything/AFFiNE?style=social&color=white)](https://github.com/toeverything/AFFiNE/stargazers)  
  **Notion-meets-Miro workspace**, MIT/AGPL licensed (sync server uses separate non-FOSS license). Combines docs, whiteboards, and databases in a local-first tool. Mobile Edgeless canvas is view-only without experimental features [citation:18]. 🎨

- **[Notesnook](https://github.com/streetwriters/notesnook)** [![Stars](https://img.shields.io/github/stars/streetwriters/notesnook?style=social&color=white)](https://github.com/streetwriters/notesnook/stargazers)  
  **Fully open-source, end-to-end encrypted note-taking**, GPL-3.0 licensed. Rich-text editing, Markdown, reminders, attachments, cross-platform. Free tier: 50 MB/month storage, 50 notebooks, unlimited notes [citation:1][citation:9]. 🔐

- **[Standard Notes](https://github.com/standardnotes/app)** [![Stars](https://img.shields.io/github/stars/standardnotes/app?style=social&color=white)](https://github.com/standardnotes/app/stargazers)  
  **Privacy-focused, E2EE note-taking**, AGPL-3.0 licensed. Free tier: plain-text notes, unlimited device sync, tags, offline access. Paid tier adds Markdown, checklists, spreadsheets, and web clipper. Encryption and device count are never limited by paywall [citation:1]. 🛡️

- **[Memos](https://github.com/usememos/memos)** [![Stars](https://img.shields.io/github/stars/usememos/memos?style=social&color=white)](https://github.com/usememos/memos/stargazers)  
  **Lightweight, self-hosted memo hub**, MIT licensed. Privacy-first, Go/React stack. Quick capture for thoughts and snippets with tag organization [citation:9]. 💡

- **[Trilium Notes](https://github.com/zadam/trilium)** [![Stars](https://img.shields.io/github/stars/zadam/trilium?style=social&color=white)](https://github.com/zadam/trilium/stargazers)  
  **Hierarchical note-taking for knowledge bases**, AGPL-3.0 licensed. Tree-structured notes with cloning, scripting, and relation maps. Self-hosted sync server available. 🌳

- **[Zettlr](https://github.com/Zettlr/Zettlr)** [![Stars](https://img.shields.io/github/stars/Zettlr/Zettlr?style=social&color=white)](https://github.com/Zettlr/Zettlr/stargazers)  
  **Markdown editor for academics and researchers**, GPL-3.0 licensed. Citation support (BibTeX, CSL), Zettelkasten workflows, and PDF export. Electron-based [citation:9]. 🎓

- **[SilverBullet](https://github.com/silverbulletmd/silverbullet)** [![Stars](https://img.shields.io/github/stars/silverbulletmd/silverbullet?style=social&color=white)](https://github.com/silverbulletmd/silverbullet/stargazers)  
  **Self-hosted PWA for markdown notes**, MIT licensed. Wiki-style linking, queries, and extensibility via plugs. Runs in browser with optional sync. ⚡

- **[Flatnotes](https://github.com/dullage/flatnotes)** [![Stars](https://img.shields.io/github/stars/dullage/flatnotes?style=social&color=white)](https://github.com/dullage/flatnotes/stargazers)  
  **Self-hosted, database-less note-taking**, MIT licensed. Plain-text Markdown files, full-text search, and tag filtering. Python/Vue stack [citation:9]. 📂

- **[HedgeDoc](https://github.com/hedgedoc/hedgedoc)** [![Stars](https://img.shields.io/github/stars/hedgedoc/hedgedoc?style=social&color=white)](https://github.com/hedgedoc/hedgedoc/stargazers)  
  **Real-time collaborative markdown notes**, AGPL-3.0 licensed. Community successor to CodiMD. Live editing, presentation mode, and export options [citation:9]. 🤝

- **[Outline](https://github.com/outline/outline)** [![Stars](https://img.shields.io/github/stars/outline/outline?style=social&color=white)](https://github.com/outline/outline/stargazers)  
  **Fast, collaborative team knowledge base**, BSL-1.1 licensed. Notion-style wiki with real-time collaboration, self-hosted or cloud [citation:9]. 🏢

- **[Docmost](https://github.com/docmost/docmost)** [![Stars](https://img.shields.io/github/stars/docmost/docmost?style=social&color=white)](https://github.com/docmost/docmost/stargazers)  
  **Open-source collaborative wiki and documentation**, AGPL-3.0 licensed. Notion/Confluence alternative with real-time collaboration, diagrams, and permissions [citation:9]. 📚

- **[TiddlyWiki](https://github.com/TiddlyWiki/TiddlyWiki5)** [![Stars](https://img.shields.io/github/stars/TiddlyWiki/TiddlyWiki5?style=social&color=white)](https://github.com/TiddlyWiki/TiddlyWiki5/stargazers)  
  **Self-contained JavaScript wiki**, BSD-3-Clause licensed. Single HTML file that works offline, with plugins, themes, and flexible content organization [citation:9]. 📦

- **[TidGi](https://github.com/tiddly-gittly/TidGi-Desktop)** [![Stars](https://img.shields.io/github/stars/tiddly-gittly/TidGi-Desktop?style=social&color=white)](https://github.com/tiddly-gittly/TidGi-Desktop/stargazers)  
  **Customizable PKM with git backup**, MPL-2.0 licensed. Based on TiddlyWiki, adds Git version control and blogging platform capabilities [citation:9]. 🔧

- **[Dokuwiki](https://github.com/dokuwiki/dokuwiki)** [![Stars](https://img.shields.io/github/stars/dokuwiki/dokuwiki?style=social&color=white)](https://github.com/dokuwiki/dokuwiki/stargazers)  
  **Simple, versatile open-source wiki**, GPL-2.0 licensed. No database required — stores content as plain text files. Extensive plugin ecosystem [citation:9]. 📖

- **[Fossil](https://github.com/drhsqlite/fossil-mirror)** [![Stars](https://img.shields.io/github/stars/drhsqlite/fossil-mirror?style=social&color=white)](https://github.com/drhsqlite/fossil-mirror/stargazers)  
  **Source control with built-in wiki**, BSD-2-Clause licensed. Self-contained distributed version control with wiki pages, bug tracking, and forum [citation:9]. 🦴

- **[Inkwell](https://github.com/lniq/inkwell)** [![Stars](https://img.shields.io/github/stars/lniq/inkwell?style=social&color=white)](https://github.com/lniq/inkwell/stargazers)  
  **Portable Markdown editor**, Source-available licensed. Split view, live preview, themes, templates, focus mode, and diff viewer. Tauri/Rust [citation:9]. ✒️

- **[Tangent Notes](https://github.com/tangentnotes/tangent)** [![Stars](https://img.shields.io/github/stars/tangentnotes/tangent?style=social&color=white)](https://github.com/tangentnotes/tangent/stargazers)  
  **Local-first markdown note-taking**, Source-available licensed. Designed for writers who want to follow their thinking without distraction [citation:9]. ✍️

- **[Stik](https://github.com/StikNotes/stik)** [![Stars](https://img.shields.io/github/stars/StikNotes/stik?style=social&color=white)](https://github.com/StikNotes/stik/stargazers)  
  **Instant thought capture for macOS**, MIT licensed. Global hotkey summons a post-it note — type and close. Notes stored as plain markdown files [citation:9]. ⚡

- **[NattyNote](https://github.com/eliaszon/natty-note)** [![Stars](https://img.shields.io/github/stars/eliaszon/natty-note?style=social&color=white)](https://github.com/eliaszon/natty-note/stargazers)  
  **Time-stamped YouTube notes browser extension**, GPL-3.0 licensed. Take notes synced to video timestamps directly from the browser [citation:9]. 🎬

## 🛠️ How to Contribute

Contributions are welcome! Follow these steps to submit new note-taking apps or open-source knowledge management software:

1. 🍴 **Fork** the repository.
2. 📝 **Add/edit** entries in `README.md` maintaining table/list structure and formatting.
3. 🔗 Include project title, official website/GitHub link, exact Stars_Count, license, and brief description.
4. 🚀 Submit a **Pull Request** with a descriptive summary of your changes.
