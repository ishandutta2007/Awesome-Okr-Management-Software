## 🔓 Open-Source GitHub Projects

*Sorted by GitHub_Stars_Count (Descending)* 🌟

- **[Operately](https://github.com/Operately/Operately)** [![Stars](https://img.shields.io/github/stars/Operately/Operately?style=social&color=white)](https://github.com/Operately/Operately/stargazers)  
  **Open-source company operating system with built-in OKRs**, Apache-2.0 licensed. Opinionated workflows for goal reviews, project check-ins, and team alignment. Self-hostable, flat-rate (no per-seat pricing), CLI & API access for AI agents. Best for teams of 5–100 [citation:3].

- **[OpenProject](https://github.com/opf/openproject)** [![Stars](https://img.shields.io/github/stars/opf/openproject?style=social&color=white)](https://github.com/opf/openproject/stargazers)  
  **Mature open-source project management with OKR module**, GPL-3.0 licensed. Full OKR tracking integrated with Gantt charts, agile boards, and work packages. Community edition free for self-hosting.

- **[Focalboard](https://github.com/mattermost/focalboard)** [![Stars](https://img.shields.io/github/stars/mattermost/focalboard?style=social&color=white)](https://github.com/mattermost/focalboard/stargazers)  
  **Open-source project management with goal boards**, MIT licensed. Kanban and table views for OKR tracking with custom properties, checklists, and inline comments. Extremely lightweight.

- **[Obsidian OKR Manager](https://github.com/jingmengzhiyue/obsidian-okr-manager)** [![Stars](https://img.shields.io/github/stars/jingmengzhiyue/obsidian-okr-manager?style=social&color=white)](https://github.com/jingmengzhiyue/obsidian-okr-manager/stargazers)  
  **Obsidian plugin for local-first OKR management**, MIT licensed. Dashboard view, check-in logging, auto progress tracking, and full Markdown/frontmatter storage. Privacy-focused with no network dependency or telemetry [citation:8].

- **[OKR System (Vue + Spring Boot)](https://github.com/zhouwenjun-hub/okr)** [![Stars](https://img.shields.io/github/stars/zhouwenjun-hub/okr?style=social&color=white)](https://github.com/zhouwenjun-hub/okr/stargazers)  
  **Enterprise OKR platform**, GPL-3.0 licensed. Vue 2 + Spring Boot 3.2 + MySQL. Features alignment tree visualization, dashboard analytics, department management, and period archiving [citation:13].

- **[BurningOKR](https://github.com/BurningOKR/BurningOKR)** [![Stars](https://img.shields.io/github/stars/BurningOKR/BurningOKR?style=social&color=white)](https://github.com/BurningOKR/BurningOKR/stargazers)  
  **Full-featured enterprise OKR platform**, Apache-2.0 licensed. Angular + Java Spring Boot + PostgreSQL. Originally developed by BROCKHAUS AG. Multi-level alignment and permission management.

- **[OKR Server (NestJS)](https://github.com/wsuo/okr-server)** [![Stars](https://img.shields.io/github/stars/wsuo/okr-server?style=social&color=white)](https://github.com/wsuo/okr-server/stargazers)  
  **OKR & performance appraisal backend**, MIT licensed. NestJS + TypeScript + MySQL. JWT auth, multi-role management, department hierarchy, and performance evaluation templates.

- **[okr-tracker (Oslo Kommune)](https://github.com/oslokommune/okr-tracker)** [![Stars](https://img.shields.io/github/stars/oslokommune/okr-tracker?style=social&color=white)](https://github.com/oslokommune/okr-tracker/stargazers)  
  **Front-end OKR & KPI tracker for product teams**, MIT licensed. Built with Vue and Firebase backend. Used by Oslo municipality for public sector goal tracking.

- **[Brag Frog](https://github.com/gruberb/brag-frog)** [![Stars](https://img.shields.io/github/stars/gruberb/brag-frog?style=social&color=white)](https://github.com/gruberb/brag-frog/stargazers)  
  **Daily workflow & OKR check-in tool**, MIT licensed. Syncs from GitHub, Jira, Google Calendar, and more. Measurable OKRs with numeric/boolean/milestone key results, auto-scoring, and AI self-review drafts (BYOK).

- **[okr2go](https://github.com/oxisto/okr2go)** [![Stars](https://img.shields.io/github/stars/oxisto/okr2go?style=social&color=white)](https://github.com/oxisto/okr2go/stargazers)  
  **Simple local OKR tracker using Markdown**, MIT licensed. No server required — just a Markdown file. Go-based CLI for personal or small-team goal tracking.

- **[Kanboard](https://github.com/kanboard/kanboard)** [![Stars](https://img.shields.io/github/stars/kanboard/kanboard?style=social&color=white)](https://github.com/kanboard/kanboard/stargazers)  
  **Open-source Kanban project management**, MIT licensed. Simple, self-hostable task management that can be adapted for OKR tracking via custom workflows and plugins [citation:9].

- **[Wekan](https://github.com/wekan/wekan)** [![Stars](https://img.shields.io/github/stars/wekan/wekan?style=social&color=white)](https://github.com/wekan/wekan/stargazers)  
  **Open-source Kanban board**, MIT licensed. Self-hostable Trello alternative with swimlanes, custom fields, and webhooks — flexible foundation for goal tracking [citation:9].

- **[Vikunja](https://github.com/go-vikunja/vikunja)** [![Stars](https://img.shields.io/github/stars/go-vikunja/vikunja?style=social&color=white)](https://github.com/go-vikunja/vikunja/stargazers)  
  **Open-source task and project management**, AGPL-3.0 licensed. Combines simple tasks with Kanban views, self-hostable for teams seeking lightweight goal tracking [citation:9].
